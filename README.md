# Taha Sohail - Portfolio Website

A modern, responsive personal portfolio website showcasing software development skills and services.

## 🚀 Live Features

- **Dark/Light Mode Toggle** - Seamless theme switching with persistent preferences
- **Smooth Animations** - Professional bars entry animation, scroll reveals, and hover effects
- **Responsive Design** - Optimized for all screen sizes (mobile, tablet, desktop)
- **Interactive Elements** - Animated typing effect, floating elements, and glowing accents

## 📂 Project Structure

```
Portfolio/
├── index.html      # Main HTML structure
├── styles.css      # Complete styling with animations
├── image.jpeg      # Profile image
├── project1.png    # SeaRoute Navigator project image
├── project2.png    # Magical Pet Kingdom project image
├── project3.png    # Tic-Tac-Toe SFML project image
└── README.md       # Project documentation
```

## 🛠️ Technologies Used

- **HTML5** - Semantic markup structure
- **CSS3** - Modern styling with CSS variables, flexbox, and grid
- **JavaScript** - Smooth scrolling, theme toggle, and scroll animations
- **Boxicons** - Icon library for UI elements
- **Google Fonts** - Poppins & Orbitron font families

## 📱 Sections

1. **Home** - Hero section with animated text roles and profile image
2. **About** - Personal introduction with key statistics
3. **Services** - C++ Programming, Python & ML, and Web Development offerings
4. **Projects** - Showcase of completed projects with GitHub links
5. **Contact** - Contact form and direct communication options
6. **Footer** - Social media links and call-to-action
